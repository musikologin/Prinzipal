# Prinzipal

Sebastians Assistenz-App für die Kirchenmusik.

- App im Browser: https://prinzipal.web.app
- Android-App: https://prinzipal.web.app/Prinzipal.apk

## Mit Claude weiterarbeiten

1. In Claude das GitHub-Konto verbinden und dieses Repository auswählen.
2. Den Wunsch einfach hineinsprechen, zum Beispiel: „Im Kalender soll die Woche am Montag beginnen.“
3. Claude ändert den Quelltext und lädt ihn hoch. Ein paar Minuten später ist die Änderung in der App,
   nach einmal Schließen und Öffnen.

Was Claude über den Aufbau wissen muss, steht in `CLAUDE.md`.
